
##  How to Run Locally

### Quick Start:
```bash
./run.sh
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Or with npm:
```bash
PATH="$(pwd)/.node/bin:$PATH" npm run dev
```
